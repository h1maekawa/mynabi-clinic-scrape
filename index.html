TOOLS

用途に合わせて使い分ける 2 つの独立した拡張機能

拡張機能 #1

Mynavi Clinic Scraper

対象: clinic.mynavi.jp

マイナビクリニックの記事一覧ページを自動巡回し、各記事内の クリニック情報ブロック（.post-clinic-block）を解析。 医院名・電話番号・午前/午後の診療時間・休診日を構造化して抽出します。

午後始 / 午後終
休診日
extension/ フォルダを Chrome に読み込む
拡張機能 #2

Doctors File Scraper

対象: doctorsfile.jp

ドクターズ・ファイルの検索一覧から 「取材記事あり」 （result-link__article）クリニックのみを選別・巡回。 医師名・住所・最寄駅・診療時間・紹介文など詳細情報を抽出します。

HOW TO USE

いずれのツールも同じ手順でインストール・実行できます

01

リポジトリをダウンロード

GitHub からリポジトリをクローンまたは ZIP でダウンロードします。使いたいツールのフォルダ（extension/ または df-extension/）を用意します。

02

Chrome に拡張機能を読み込む

chrome://extensions/ を開き、右上の「デベロッパー モード」を ON にして「パッケージ化されていない拡張機能を読み込む」から対象フォルダを選択します。

03

実行 → CSV / JSON 保存

ツールバーのアイコンから「スクレイパーを開く」をクリック。開始 URL・上限ページ数・待機秒を設定して「実行」。完了後に CSV / JSON をダウンロード。
